# Enunciado 

Cálculo de Promedio: Leer tres notas de un estudiante y calcular su promedio. Mostrar el resultado en pantalla.

# Analisis

Para el algoritmo definí las 3 variables las cuales tendrán la información de las notas, de ahí se realiza una suma y se divide por 3 para poder obtener el promedio de la nota.

# Pseudocodigo

Algoritmo CalculoPromedio

	Escribir "Ingrese las 3 calificaciones para calcular"
	Leer c1
	Leer c2
	Leer c3
	promedio=(c1+c2+c3)/3
	Escribir "El caluclo de tu promedio es: ", promedio

FinAlgoritmo
